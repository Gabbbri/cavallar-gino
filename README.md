# Cavallar Gino SNC

Sito statico: HTML, CSS, JavaScript e immagini. Nessuna build o dipendenza npm.

Apri index.html nel browser, oppure esegui `python3 -m http.server 8000` nella cartella e apri http://localhost:8000.

GitHub Pages: pubblicazione dal ramo main, cartella root (/).
Tutti i percorsi delle risorse sono relativi e funzionano anche sotto /cavallar-gino/.
I font vengono caricati da Google Fonts. Il modulo contatti apre il programma email; WhatsApp e telefono sono collegamenti diretti.
